# Online Retail Customer Segmentation

## Project Overview

This project focuses on customer segmentation using the Online Retail dataset.

The goal is to identify groups of customers with similar purchasing behavior using RFM analysis and K-Means clustering.

## Methodology

The project follows these main steps:

1. Data Cleaning
2. Exploratory Data Analysis
3. RFM Analysis
4. Log Transformation
5. Feature Scaling
6. Elbow Method
7. Silhouette Score
8. K-Means Clustering
9. Customer Segmentation
10. Business Insights

## RFM Analysis

Three customer-level features were calculated:

- **Recency:** Number of days since the customer's last purchase
- **Frequency:** Number of purchases made by the customer
- **Monetary:** Total revenue generated by the customer

## Clustering

K-Means clustering was applied to the transformed and scaled RFM features.

Based on the clustering evaluation, **K = 2** was selected.

The Silhouette Score for K = 2 was approximately **0.433**.

## Customer Segments

### Cluster 0 — Low-Value / Inactive Customers

- Customers: 2,671
- Average Recency: 134.1 days
- Average Frequency: 1.67
- Average Monetary: £497.74
- Revenue Share: 14.9%

### Cluster 1 — High-Value / Active Customers

- Customers: 1,667
- Average Recency: 25.9 days
- Average Frequency: 8.44
- Average Monetary: £4,548.26
- Revenue Share: 85.1%

## Key Business Insight

Approximately **38.4% of customers generate 85.1% of total revenue**.

This indicates that the High-Value / Active customer segment is particularly important for customer retention and loyalty strategies.

The Low-Value / Inactive segment can be targeted with reactivation campaigns, personalized offers, and incentives to encourage repeat purchases.
